Here’s a clear and beginner-friendly explanation of file handling 
in Python, along with simple examples that you can run.

✅ What is File Handling?

File handling means reading from or writing to files stored on 
your computer.
Python provides built-in functions like:

open()

read()

write()

close()

📌 Opening a File

Python uses the open() function:

file = open("example.txt", "r")


The second argument is the mode:

Mode	Meaning
"r"	Read (file must exist)
"w"	Write (creates or overwrites file)
"a"	Append (adds to end of file)
"r+"	Read and write
✍️ Example 1: Writing to a File
# create or overwrite a file
f = open("demo.txt", "w")
f.write("Hello! This is my first file.\n")
f.write("Python is awesome!")
f.close()


After running, a file named demo.txt will be created.

📖 Example 2: Reading a File
f = open("demo.txt", "r")
content = f.read()
print(content)
f.close()


Output will be the content inside the file.

➕ Example 3: Append to a File

Adds text without deleting old content:

f = open("demo.txt", "a")
f.write("\nThis line was added later.")
f.close()

🔄 Better way: Using with (Auto-close)

Using with automatically closes the file for you (recommended).

✔ Write with with
with open("demo.txt", "w") as f:
    f.write("Using WITH is safer and easier!")

✔ Read with with
with open("demo.txt", "r") as f:
    print(f.read())

📌 Example 4: Reading Line by Line
with open("demo.txt", "r") as f:
    for line in f:
        print(line.strip())

📌 Example 5: Check if File Exists (optional)
import os

if os.path.exists("demo.txt"):
    print("The file exists!")
else:
    print("File not found!")
