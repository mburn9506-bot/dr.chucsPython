In Python, a void function (also called a non-fruitful function) is a function that does NOT return a value.
It performs an action (printing, updating data, writing a file, etc.) but does not give a result back with return.

✅ Example of a void (non-fruitful) function
def greet(name):
    print("Hello", name)


Calling it:

greet("Mike")


Output:

Hello Mike


This function does something (prints) but returns None.

🔍 How to check its return value
result = greet("Mike")
print(result)


Output:

Hello Mike
None

🆚 Fruitful vs non-fruitful (void) functions
Type	Returns a value?	Example
Fruitful function	Yes	return a + b
Void function	No	print("Hello")

Example of fruitful:

def add(a, b):
    return a + b
