In Python, data structures are ways to store and 
organize data so you can use it efficiently.
 Here are the main Python data structures, 
 with simple explanations and examples 👇

1️⃣ List
Ordered, mutable (can change)
Allows duplicate values
numbers = [1, 2, 3, 4]
numbers.append(5)
print(numbers)
✅ Use when you need a collection that can change

2️⃣ Tuple
Ordered, immutable (cannot change)

Faster than lists
coordinates = (10, 20)
print(coordinates[0])
✅ Use for fixed data (e.g., coordinates, settings)

3️⃣ Set
Unordered
No duplicates
unique_numbers = {1, 2, 3, 3, 4}
print(unique_numbers)
✅ Use to remove duplicates or check membership quickly

4️⃣ Dictionary (Dict)
Stores data as key → value
Very fast lookups


student = {
    "name": "Ali",
    "age": 15,
    "grade": "10th"
}
print(student["name"])

✅ Use when data has labels (like JSON)
5️⃣ String

Sequence of characters

Immutable
text = "Hello Python"
print(text.upper())


6️⃣ Stack (using list)
LIFO (Last In, First Out)
stack = []
stack.append(10)
stack.append(20)
stack.pop()

7️⃣ Queue (using collections.deque)

FIFO (First In, First Out)
from collections import deque
queue = deque()
queue.append(1)
queue.append(2)
queue.popleft()

8️⃣ Nested Data Structures
Combine multiple structures
students = [
    {"name": "Ali", "age": 14},
    {"name": "Sara", "age": 15}
]

📘 Data Structures (Exam Explanation)
🔹 What is a Data Structure?
A data structure is a way of organizing, storing, and managing data so it can be accessed and modified efficiently.

🔹 Why are Data Structures Important?
They make programs faster
They use memory efficiently
They help manage large amounts of data
They make code easier to understand

📌 Types of Data Structures in Python
1️⃣ List
Definition (Exam):
A list is an ordered and mutable collection of elements that allows duplicate values.

Example:
L = [10, 20, 30]
Key Points:
Ordered
Changeable (mutable)
Allows duplicates

2️⃣ Tuple
Definition (Exam):
A tuple is an ordered but immutable collection of elements.

Example:
T = (10, 20, 30)
Key Points:
Ordered
Cannot be changed
Faster than lists
3️⃣ Set
Definition (Exam):
A set is an unordered collection of unique elements.

Example:

S = {1, 2, 3}
Key Points:
Unordered
No duplicate values
Mutable

4️⃣ Dictionary
Definition (Exam):
A dictionary is a collection of key-value pairs used to store related data.

Example:
D = {"name": "Ali", "age": 15}
Key Points:
Keys must be unique
Fast searching
Mutable

5️⃣ String
Definition (Exam):
A string is a sequence of characters enclosed in quotes.

Example:
name = "Python"
Key Points:
Ordered
Immutable
